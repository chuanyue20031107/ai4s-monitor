## 动态任务提示词

执行 AI4S Monitor 一次性全量未分析情报清理任务。启动时读取仓库最新 main 的 data/queue.json、data/raw、data/receipts.json 和近期 inbox，动态计算所有未分析记录；不要使用固定数量（包括 723）。目标集合以启动时快照为基准，并在每批后重新扫描，执行期间新增的未分析记录也加入，直到一次完整扫描显示 pending=0。对每条记录读取最新 raw 和 contentHash；缺正文先按原 URL 用现有采集/补抓能力获取，遵守 robots、登录、验证码和付费墙边界。正文充分后逐条生成符合 docs/chatgpt-analysis.md 的真实中文分析，证据必须逐字来自当前 raw.content。每批最多30条、inbox单文件最多50条只是批次大小，提交 accepted 后继续下一批，不能因此停止。只新增唯一 data/inbox JSON，由 publisher 校验并发布 Pages；检查 accepted 回执、Actions deploy 成功和线上 articles.json/analysis-status.json。维护动态 checkpoint、已完成、失败、缺正文、剩余 ID 和提交链接。只有实时 pending=0、目标全部有效 done 且 Pages 验证成功时才宣布完成；failed/discarded/缺正文不算 done。此任务完成后停止，不创建持续任务。
